# V3.4 — correção RLS de `lead_events`

## Quando executar
Execute `supabase/migration_v3_2_lead_events_rls_hotfix.sql` no SQL Editor do Supabase quando o painel exibir:

`new row violates row-level security policy for table "lead_events"`

## Efeito
- mantém o RLS ativo;
- permite que o usuário autenticado leia e insira somente os próprios eventos;
- preserva a auditoria da validação e da revalidação do Pré-Envio;
- tenta vincular eventos antigos ao mesmo `user_id` do lead de origem, sem sobrescrever eventos já vinculados.

Não apaga leads, pré-envio, filas ou eventos.
