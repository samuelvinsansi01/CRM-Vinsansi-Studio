# V3.3 — Revalidação de aprovados no Pré-Envio

Esta versão adiciona uma ação segura na área **Pré-Envio > WhatsApp**: **Revalidar aprovados**.

## O que a ação faz

- Atua apenas nos leads WhatsApp com status `approved` dentro do dia, chip e filtro atualmente abertos.
- Reconsulta o mesmo worker configurado em `VITE_WHATSAPP_WORKER_VALIDATE_ENDPOINT`, que por sua vez chama a Evolution API.
- Mantém como `approved` somente o número com confirmação explícita de WhatsApp.
- Move para `review` qualquer número inválido, resposta ambígua ou erro de provider.
- Atualiza `validationStatus`, `validationAttempts` e `lastValidatedAt`.
- Registra o resultado em `lead_events` como `whatsapp_revalidation_approved` quando o número é confirmado.

## O que ela não faz

- Não envia nenhum lead para as filas.
- Não altera leads já em `queued`, `sent` ou `archived`.
- Não devolve automaticamente nenhum lead para Instagram, mesmo que uma configuração antiga ainda tenha essa preferência.

## Como usar

1. Publique esta versão após garantir que `DRY_RUN=false` na Vercel Production.
2. Abra **Pré-Envio > WhatsApp** e selecione o dia/chip desejado.
3. Para revalidar todos os aprovados visíveis no escopo, clique em **Revalidar aprovados** sem selecionar linhas.
4. Para revalidar apenas alguns, marque somente linhas com status **Aprovado** e clique no mesmo botão.
5. Revise os itens que forem movidos para **Revisão** antes de qualquer envio à fila.
